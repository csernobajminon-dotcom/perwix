# Perwix boot artwork

The GRUB theme follows the classic FreeBSD text-loader composition while using
Perwix branding. The upper-left `PERWIX` wordmark and the double-line
`Welcome to Perwix` menu frame are part of `grub/themes/perwix/background.png`.
The colored emblem on the right is generated by sampling the character data in
`kernel/core/logo.c`; its character palette is the same one used by the kernel
console (`$`, `X`, `x`, `+`, `:`, `;`).

The menu itself is not baked into the PNG: GRUB draws the selectable, live menu
entries over the frame. This keeps arrow-key selection, Enter, the timeout,
and the Boot Options submenu interactive. `grub/themes/perwix/theme.txt`
controls placement and spacing.
